# v0.2 Bounded Tunnel Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop persistent tunnel instability, retain provider child ownership and prove recovery/shutdown through real CLI processes.

**Architecture:** Lifecycle keeps resource and signal ownership. A small tunnel recovery policy owns the consecutive-event count, backoff and current-budget cause; runPeek applies it without replacing the verified dev target. Cloudflare owns one child and one pending disconnect.

**Tech Stack:** Strict TypeScript, Node 22+, existing Execa 10, Vitest 5, tsdown and the existing loopback CLI harness. No dependency change.

**Spec:** [approved design](../specs/2026-10-04-v02-reconnect-design.md).

**Baseline:** main `a54a661`; branch `fix/v02-reconnect`; draft PR #15.

## Global Constraints

- Allow eight consecutive instability events: one recoverable failed connect or one resolved session exit counts once.
- A session lasting at least 30 seconds resets count, delay and current-budget cause before its drop counts as event one. Mere readiness does not reset anything.
- Retain delays 1, 2, 4, 8, 16, 30, 30 seconds after events one through seven; no delay before initial connect and no ninth attempt after exhaustion.
- Keep the original dev process and verified numeric-loopback target. Cancel promptly during backoff; dev exit and nonrecoverable errors remain terminal.
- Preserve schemaVersion 1, existing event fields, lifetime failed-connect warning numbering, existing status mapping and first-signal precedence.
- Exhaustion uses TUNNEL_CONNECTION_ERROR with a remedy and no stack; a stable reset clears an obsolete failure cause.
- Cloudflare must reject overlapping connect before launch or diagnostics mutation, including pending teardown. Retain unconfirmed children, share pending disconnect and dispose stream listeners on observed exit.
- Keep provider teardown's three-second graceful and one-second forced confirmation budgets, all binary pins/checks, argv execution and LAN behavior.
- Add no public option, config, dependency, package export, provider or v0.3 runtime. Process-tree adversarial fixes are the next dependent PR.
- No public Cloudflare dependency in normal tests. Real process tests assert recorded resources stopped before fallback disposal.
- Run the six final local gates sequentially; test setup rebuilds dist.

```ts
import { PeekError } from '../utils/errors.js'

const DEFAULT_DELAYS = [1000, 2000, 4000, 8000, 16000, 30000]

export class TunnelRecovery {
  private events = 0
  private lastFailure: unknown = undefined
  private readonly delays: readonly number[]

  constructor(delays: readonly number[] = DEFAULT_DELAYS) {
    this.delays = delays.length ? delays : DEFAULT_DELAYS
  }

  get delayMs(): number {
    return this.events === 0
      ? 0
      : (this.delays[Math.min(this.events - 1, this.delays.length - 1)] ?? 30000)
  }

  failed(error: unknown): void {
    this.lastFailure = error
    this.recordEvent()
  }

  dropped(milliseconds: number): void {
    if (milliseconds >= 30000) {
      this.events = 0
      this.lastFailure = undefined
    }
    this.recordEvent()
  }

  private recordEvent(): void {
    this.events++
    if (this.events >= 8) {
      throw new PeekError(
        'TUNNEL_CONNECTION_ERROR',
        'Tunnel recovery stopped after eight consecutive failures or drops.',
        'Check your network with peek doctor, use --verbose for details, and restart Peek after fixing the problem.',
        this.lastFailure,
      )
    }
  }
}
```

      const waited = await waitForOutcome(
        delay(waitMs, undefined, { signal }).catch(() => undefined),
        dev.exit,
        signal,
      )
      if (waited.kind === 'cancel') return
      if (waited.kind === 'dev') throw serverExit(waited.exit)
      signal.throwIfAborted()
    }
    signal.throwIfAborted()
    const disconnected = await waitForOutcome(provider.disconnect(), dev.exit, signal)
    if (disconnected.kind === 'cancel') return
    if (disconnected.kind === 'dev') throw serverExit(disconnected.exit)
    signal.throwIfAborted()
    try {
      const connected = await waitForOutcome(
        provider.connect({ target: new URL(`http://127.0.0.1:${port}`), signal }),
        dev.exit,
        signal,
      )
      if (connected.kind === 'cancel') return
      if (connected.kind === 'dev') throw serverExit(connected.exit)
      signal.throwIfAborted()
      connection = connected.value
      connectedAt = now()
    } catch (error) {
      if (
        error instanceof PeekError &&
        (error.code === 'SERVER_START_ERROR' || error.code === 'TUNNEL_CONFIG_ERROR')
      ) throw error
      signal.throwIfAborted()
      failureCount++
      options.onReconnectFailure?.(
        failureCount,
        error instanceof Error ? error.message : String(error),
      )
      signal.throwIfAborted()
      recovery.failed(error)
    }
  }
  reportReady(connection)
  const outcome = await waitForOutcome(connection.exited, dev.exit, signal)
  if (outcome.kind === 'cancel') return
  if (outcome.kind === 'dev') throw serverExit(outcome.exit)
  signal.throwIfAborted()
  options.onTunnelDrop?.(
    `Tunnel exited with code ${outcome.value.exitCode ?? 'unknown'}.`,
  )
  signal.throwIfAborted()
  previewController?.abort()
  lifecycle.advance('reconnecting')
  options.onState?.('reconnecting')
  signal.throwIfAborted()
  recovery.dropped(now() - connectedAt)
  connection = undefined
}
