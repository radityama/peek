# Peek v0.2 Discovery Implementation Plan

> **For agentic workers:** Implement the checkbox steps in order. Keep process inspection injectable and run the focused tests before each commit.

**Goal:** Find the dev server port across common frameworks and platforms without exposing an unrelated service.

**Architecture:** Keep output parsing in `src/core/port.ts` and move OS process inspection from `src/core/server.ts` to a dedicated module. `waitForServer` reconciles evidence in the order specified by the design.

**Tech Stack:** Node.js 22+, strict TypeScript, Vitest, Execa.

---

### Task 1: Framework output and discovery evidence

**Files:** Modify `src/core/port.ts`, `src/core/server.ts`, `src/core/run.ts`; create `src/core/framework.ts`; test `tests/unit/port.test.ts`, `tests/integration/server.test.ts`.

- [ ] Add table-driven cases with startup lines for Next.js, Vite, Astro, Nuxt, TanStack Start, React Router/Remix, SvelteKit, and generic Node; include unrelated URLs and invalid ports. Run `pnpm test tests/unit/port.test.ts` and confirm the new cases fail.
- [ ] Add `FrameworkHint` and `detectFramework(packageJson, output)` to `src/core/framework.ts`. Keep it advisory: no framework hint is port evidence.
- [ ] Extend `extractLocalPorts` to accept the supported startup patterns, retaining strict local-host matching. Run the focused unit test and confirm it passes.
- [ ] Add integration cases for explicit port, output port, owned child port, owned descendant port, newly opened common port, multiple candidates, and a reachable foreign process. Run `pnpm test tests/integration/server.test.ts`; confirm the new cases fail before implementation.
- [ ] Change `waitForServer` to apply the specified priority and reject ownership conflicts. Preserve injectable port inspection and baseline probes. Run the focused integration tests and confirm they pass.
- [ ] Commit with `git add src/core/port.ts src/core/server.ts src/core/run.ts src/core/framework.ts tests/unit/port.test.ts tests/integration/server.test.ts` and `git commit -m 'feat: improve verified dev server discovery'`.

### Task 2: Cross-platform process inspection

**Files:** Create `src/core/process-tree.ts`; modify `src/core/server.ts`, `src/core/lifecycle.ts`; test `tests/unit/process-tree.test.ts`, `tests/integration/lifecycle.test.ts`.

- [ ] Write tests for parsing Linux/macOS/Windows listener output, descendant membership, and inspection-command failure. Run `pnpm test tests/unit/process-tree.test.ts` and confirm failure.
- [ ] Move the existing OS inspection functions from `server.ts` into `process-tree.ts`; expose `inspectListeningPorts(rootPid)` and keep subprocess commands as argv arrays with bounded timeouts.
- [ ] Add a Windows lifecycle fixture that starts a child and grandchild, then asserts Ctrl+C or failure leaves no descendant. Run `pnpm test tests/integration/lifecycle.test.ts` on Windows CI.
- [ ] Run `pnpm test tests/unit/process-tree.test.ts tests/integration/server.test.ts tests/integration/lifecycle.test.ts`, `pnpm typecheck`, and commit the focused files as `feat: verify descendant listeners and cleanup`.
