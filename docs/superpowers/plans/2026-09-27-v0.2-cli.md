# Peek v0.2 CLI Modes Implementation Plan

Historical plan. The v0.2 implementation is complete; see `docs/ARCHITECTURE.md` for the shipped layout. The checkboxes below record proposed steps, not outstanding release work.

> **For agentic workers:** Implement the checkbox steps in order. Preserve the no-config default and packed Node 22 CLI behavior.

**Goal:** Add optional project configuration, LAN preview, JSON output, and a useful doctor command.

**Architecture:** The CLI resolves options into one validated run configuration. Human and JSON renderers consume typed events. Doctor reuses validators and preview checks with an optional live run.

**Tech Stack:** Node.js 22+, strict TypeScript, Citty, Vitest, a small TypeScript config loader if required for Node 22.0.

---

### Task 1: Optional configuration

**Files:** Create `src/core/config.ts`; modify `src/cli.ts`, `src/core/dev-command.ts`, `package.json`, `pnpm-lock.yaml`; test `tests/unit/config.test.ts`, `tests/integration/cli.test.ts`.

- [ ] Add fixture cases for missing config, valid default `defineConfig({ command: ['bun', 'run', 'dev'], port: 3000 })`, invalid command string, unknown key, and CLI override. Run focused tests and confirm failure.
- [ ] Implement `defineConfig` and a project-root-only loader that works on Node 22.0, then validate every field before process startup. Use `CLI > config > discovery` precedence and retain argv execution.
- [ ] Run `pnpm test tests/unit/config.test.ts tests/integration/cli.test.ts`, `pnpm typecheck`, and packed CLI smoke test. Commit as `feat: support optional project configuration`.

### Task 2: LAN mode and structured events

**Files:** Create `src/core/lan.ts`, `src/ui/json-output.ts`; modify `src/core/run.ts`, `src/cli.ts`, `src/ui/output.ts` (typed `Output` interface); test `tests/unit/lan.test.ts`, `tests/unit/json-output.test.ts`, `tests/integration/cli.test.ts`.

- [ ] Add tests for one usable private IPv4, none, ambiguity, loopback-only binding, and zero `cloudflared` starts. Run focused tests and confirm failure.
- [ ] Implement LAN address selection and probe it at the verified server port; start no tunnel or binary download in `--lan` mode.
- [ ] Add JSON event tests that parse every stdout line and reject raw child output, QR text, or decorations. Run focused tests and confirm failure.
- [ ] Implement the versioned event renderer and route all states, child output, warnings, URLs, and errors through it. Run focused tests, typecheck, and commit as `feat: add LAN and JSON modes`.

### Task 3: Doctor

**Files:** Create `src/core/doctor.ts`; modify `src/cli.ts`, `src/cloudflared/binary.ts`; test `tests/unit/doctor.test.ts`, `tests/integration/cli.test.ts`.
